# Prova de Paradigmas

Alunos: João Victor Lima Azevedo, matrícula 2022021127, e Nargylla Cloviel Lima, matrícula 2023035691.

Projeto: Sorveteria Elefantinho.

O programa foi desenvolvido utilizando o paradigma de Programação Orientada a Objetos (POO), dividido em três classes principais: Sorvete, Pedido e Sorveteria.

A classe Sorvete representa os produtos do cardápio, utilizando o método __init__ para armazenar os atributos sabor e preço.

A classe Pedido é responsável por armazenar os sorvetes escolhidos, utilizando uma lista e o método adicionar. Também possui os métodos calcular_total, responsável por calcular o valor da compra, e mostrar, que exibe os itens e o total do pedido.

A classe Sorveteria controla o funcionamento do programa. Ela possui o cardápio, cria um objeto da classe Pedido e apresenta as opções para o usuário. O método mostrar_cardapio exibe os sabores disponíveis, enquanto o método executar controla o menu e as escolhas do usuário.

O programa utiliza conceitos de POO como classes, objetos, atributos, métodos, construtor __init__ e encapsulamento de responsabilidades. Também utiliza os tipos str para os sabores, int para códigos e quantidades e float para os preços.
